df和du命令都用来查看磁盘使用情况，但**用途和粒度不同**。

------

## 一、 `df` — **查看磁盘整体使用情况**

- **作用**：显示文件系统层面的空间总量、已用和可用容量。

- 特点 ：

  - 查看磁盘分区使用情况
  - 不会显示单个文件或目录的大小

### 常用示例

1. **以人类可读方式显示**（GB/MB/KB）：

```
df -h
```

2. **显示所有文件系统，包括挂载点**：

```
df -a
```

3. **显示 inode 使用情况**：

```
df -i
```

4. **指定某个目录所在分区的使用情况**：

```
df -h /root
```

**适用场景**：

- 想快速知道哪个分区快满了
- 想了解总容量 vs 已用 vs 剩余空间

------

## 二、 `du` — **查看目录或文件占用情况**

- **作用**：显示文件和目录占用的实际空间。

- 特点 ：

  - 可以递归查看目录大小
  - 可以按文件、目录粒度排序
  - 更适合定位大文件、大目录

### 常用参数

1. **显示指定目录总大小**：

```
du -sh /root
```

- `-s`：summary，只显示总和
- `-h`：human-readable，可读格式（K/M/G）

2. **显示目录下每个子目录大小**：

```
du -sh /root/*
```

3. **递归查看并排序**：

```
du -ah /root | sort -hr | head -20
```

- `-a`：显示所有文件
- `sort -hr`：按大小倒序
- `head -20`：只显示前 20 个

4. **限制深度**：

```
du -h --max-depth=1 /usr
```

- `--max-depth=1`：只显示 `/usr` 下一级目录大小

**适用场景**：

- 想找大文件、大目录
- 想分析磁盘空间被哪些文件占用
- 清理 `/root/src`、`/usr/local` 等开发目录

------

### 🔹 总结

| 命令 | 粒度          | 用途                             |
| ---- | ------------- | -------------------------------- |
| `df` | 分区/文件系统 | 查看总容量、剩余空间、使用率     |
| `du` | 目录/文件     | 查看目录或文件实际占用，找大文件 |
