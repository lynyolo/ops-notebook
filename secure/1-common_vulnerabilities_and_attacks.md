下面按“漏洞类型 → 攻击原理 → 防御思路”整理常见安全问题（偏Web/系统通用）。

------

## 1. SQL 注入（SQL Injection）

**攻击原理**

- 应用把用户输入拼接进 SQL 语句
- 攻击者构造恶意 SQL（如 `' OR 1=1 --`）
- 导致数据库执行非预期查询、删除或泄露数据

**防御思路**

- 使用**参数化查询 / Prepared Statement**
- ORM（正确使用情况下）
- 输入校验（白名单）
- 最小权限数据库账号（禁止 DROP/ALTER）
- 禁止拼接 SQL 字符串

------

## 2. XSS（跨站脚本攻击）

**攻击原理**

- 恶意脚本注入页面（存储型/反射型/DOM型）
- 用户浏览页面时执行 JS
- 窃取 Cookie、Token、劫持会话

**防御思路**

- 输出编码（HTML/JS/URL escape）
- CSP（Content Security Policy）
- 过滤危险标签（但不能只依赖过滤）
- HttpOnly Cookie（防止 JS 读取）
- 避免 innerHTML 直接拼接

------

## 3. CSRF（跨站请求伪造）

**攻击原理**

- 用户已登录网站 A
- 攻击者诱导访问恶意站点 B
- B 触发 A 的请求（利用浏览器自动带 Cookie）

**防御思路**

- CSRF Token（核心）
- SameSite Cookie（Lax/Strict）
- 验证 Referer/Origin
- 关键操作二次确认

------

## 4. 文件上传漏洞

**攻击原理**

- 上传 WebShell（如 PHP/ASP）
- 或上传恶意文件触发解析执行
- 获取服务器控制权

**防御思路**

- 文件类型白名单（MIME + 后缀）
- 重命名文件（避免执行路径）
- 禁止上传目录执行权限
- 分离存储（对象存储/CDN）
- 检查文件内容（magic number）

------

## 5. 命令注入（Command Injection）

**攻击原理**

- 应用调用系统命令（如 `system()`）
- 用户输入拼接进 shell
- 注入 `; rm -rf /` 等命令

**防御思路**

- 禁止拼接命令
- 使用安全 API（替代 shell）
- 输入白名单
- 最小权限运行进程

------

## 6. SSRF（服务端请求伪造）

**攻击原理**

- 服务器替用户发起请求
- 攻击者控制 URL
- 访问内网资源（如 127.0.0.1、metadata）

**防御思路**

- URL 白名单
- 禁止访问内网 IP（127/10/172.16/192.168）
- DNS 解析校验
- 禁止重定向
- 使用隔离网络环境

------

## 7. 反序列化漏洞

**攻击原理**

- 反序列化不可信数据
- 构造 gadget chain 执行代码
- 常见于 Java/PHP/Python

**防御思路**

- 避免反序列化不可信数据
- 使用 JSON 替代二进制序列化
- 启用安全反序列化机制
- 类白名单

------

## 8. 越权访问（IDOR）

**攻击原理**

- 仅靠 ID 访问资源
- 改变 ID 即可访问他人数据
- 例如 `/user/1001` 改为 `/1002`

**防御思路**

- 服务端权限校验（核心）
- RBAC（角色权限控制）
- 不可预测资源标识（UUID）
- 每次请求验证归属关系

------

## 9. 文件包含漏洞（LFI/RFI）

**攻击原理**

- 动态 include 用户输入路径
- 本地文件读取或远程代码执行

**防御思路**

- 路径白名单
- 禁止用户控制 include 路径
- 关闭远程文件包含
- 目录限制（chroot）

------

## 10. 中间人攻击（MITM）

**攻击原理**

- 攻击者拦截通信
- 读取/篡改数据

**防御思路**

- HTTPS（TLS）
- HSTS
- 证书校验（防伪造证书）
- 公钥固定（Pinning）

------

## 11. 暴力破解 / 撞库

**攻击原理**

- 尝试大量密码
- 使用泄露账号密码库

**防御思路**

- 限速（Rate Limit）
- 验证码
- 多因素认证（MFA）
- 密码加盐哈希（bcrypt/argon2）
- 登录异常检测

------

## 12. 敏感信息泄露

**攻击原理**

- 错误配置、日志、前端暴露 API Key
- 返回过多字段

**防御思路**

- 最小化返回数据
- 配置脱敏
- 禁止 debug 模式上线
- 密钥放环境变量/密钥管理系统

------

## 总体防御原则（非常重要）

1. **输入不可信（Never trust input）**
2. **输出编码（防 XSS）**
3. **权限在服务端强校验**
4. **最小权限原则**
5. **白名单优于黑名单**
6. **安全默认配置**
7. **分层防御（Defense in depth）**
